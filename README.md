# MaevePaint

A paint program for kids. Pencils, inks, paint that blends, spray, chalk, fills, shapes and
stickers, with a sound for everything and undo that never runs out. Kids can draw on blank paper
or color in pages from the picture library.

Grown-ups get their own window for settings the child never sees: which picture and sticker sets
show, what things sound like, and downloading more sets.

## Download

Get `maevepaint.exe` from the [latest release](https://github.com/BryanCE/maevepaint-releases/releases/latest).
It's one file with nothing to install. Put it anywhere and run it.

Windows 10 or 11, 64-bit.

### "Windows protected your PC"

The app isn't code-signed, so Windows SmartScreen warns the first time you run it. Click
**More info**, then **Run anyway**.

## Coloring pages and stickers

The app starts with no picture or sticker sets, which keeps the download small. To add some, open
the grown-ups' window with the gear button at the top right or **File > Settings**, go to
**Content > Get more**, and install the sets you want. They download from the
[picture and sticker library](https://github.com/BryanCE/maevepaint-releases/releases/tag/library)
release of this repo.

Sets come from NASA, NOAA, the National Park Service, the USDA Forest Service, Wikimedia
Commons, FreeSVG, OpenMoji, Tux Paint and others. Kids find them sorted by topic, such as
Dinosaurs, Space, Ocean and Animals. A set can be turned off at any time to hide it.

## Where things are saved

- **Pictures:** the `MaevePaint` folder in your Pictures folder. Each picture saves as you draw,
  with a PNG beside it when it's closed.
- **Settings and downloaded sets:** `%APPDATA%\MaevePaint\data`.

Nothing leaves your computer. See [PRIVACY.md](PRIVACY.md).

## Bugs and ideas

Found a bug, or have an idea for a brush, sticker set or anything else? Open an
[issue](https://github.com/BryanCE/maevepaint-releases/issues/new/choose) and pick **Something's
wrong** or **Idea**. It takes a free GitHub account.

Please check the [open issues](https://github.com/BryanCE/maevepaint-releases/issues) first. If
someone already reported the same thing, add a 👍 or a comment there instead of a new issue.
For a bug, say which version you're running (Help > About MaevePaint) and how to make it happen
again; a screenshot helps a lot.
