# Changelog

## 0.1.1

- **Get more:** download picture and sticker sets from inside the app, from the grown-ups'
  window under Content > Get more. Install and remove them any time.
- **Pictures by topic:** the picture chooser shows Dinosaurs, Space, Ocean, Animals and other
  topics, each holding every picture on it from every set.
- **Content pages:** the grown-ups' window lists picture and sticker sets grouped by topic or by
  source, with a switch to hide each one.
- Sounds you pick for the app show the name of the file you chose.
- Touch draws from the screen's touch messages, with no setting to change it.
- The "more below" arrow no longer shows on empty tool options.
- Help > Credits & licenses lists every open-source part built into the app.
